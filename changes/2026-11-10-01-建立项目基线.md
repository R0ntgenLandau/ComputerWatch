# 建立项目基线

日期 2026-11-10

## 改动原因

将已有项目纳入版本管理，从此为每项调整保留可追溯的中文记录。

## 改动内容

- 初始化本地 Git，纳入现有 Windows 监控源码、构建安装脚本和项目约定。
- 建立 `changes/` 目录，约定每项调整都把中文记录和改动一同提交。
- 当前基线采用 C++ 采集和 Win32 界面，包含本机 SQLite 历史、托盘、CPU 与显卡详情及磁盘 SMART。Electron 前台方向记在项目约定中。

## 验证

- 检查 Git 暂存范围，确认包含源码和记录，`build/` 由 `.gitignore` 排除。
