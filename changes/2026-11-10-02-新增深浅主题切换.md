# 新增深浅主题切换

日期 2026-11-10

## 改动原因

允许用户按使用环境选择浅色或深色界面。

## 改动内容

- 设置页新增外观主题，浅色和深色按钮切换后即时更新界面。
- 两套配色覆盖面板、卡片、曲线、排行、详情列表和按钮。原生窗口控件按 Windows 提供的主题能力应用配色。
- 主题选择保存为当前 Windows 用户的应用偏好。首次使用默认浅色。

## 验证

- Windows C++ 构建通过。
- 隔离界面测试验证浅色和深色双向切换及背景颜色，并在两种主题下检查历史、详情返回、排行排序和托盘重开。
- 隔离偏好测试验证保存与读取，以及缺省或无效值回退到浅色。
- 更新本机安装后，确认窗口响应正常，两条计划任务运行，历史继续写入四项温度与功耗读数。
