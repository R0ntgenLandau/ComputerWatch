# 设置页新增 MCP 接入

## 原因

在设置页直接展示 MCP 入口，方便从当前程序获取客户端配置。

## 改动

- 设置页新增「MCP 客户端接入」区块，说明本机只读查询及 uv 依赖，并提供「复制客户端配置」。
- 复制的 JSON 使用当前程序旁的服务脚本路径。构建与安装随程序放置脚本，卸载时移除脚本。
- 更新 MCP 接入说明。

## 验证

- 项目根目录运行 build.ps1 成功，核对了 ComputerWatch.exe 和随附的 mcp_server.py，脚本哈希与源文件相同。
- 运行工作区测试版，使用辅助功能树确认设置页存在「复制客户端配置」按钮。窗口截图捕获超时，随后用户结束了界面操作。按钮复制结果、键盘焦点顺序和实时监控往返 CPU 详情待复核。
- 安装脚本已做语法检查，未运行安装。
