# 新增显示器信息和色域图

## 改动原因

在监控面板中查看每台已启用显示器的当前信号参数和色域。

## 改动内容

- 新增顶部「显示器」页，按 Windows 的活动显示路径读取显示器名称、信号分辨率、刷新率和连接类型。进入页面、点击刷新或收到显示配置变化通知时重新读取。
- 点击显示器行后显示 RGB 色度坐标、CIE 1931 xy 三角形及 sRGB 对照线。sRGB、Display P3 和 Adobe RGB 覆盖率按 EDID 三角形与标准三角形的交集面积计算，界面注明为估算。EDID 缺失或无效时显示缺失状态。

## 验证结果

- 编译检查：通过 `./build.ps1` 的 x64、x86 和 arm64 构建，核对三份可执行文件。
- 模拟数据检查：验证有效及无效 EDID、10 位坐标解码、完全覆盖、被包含、无交集和反向顶点顺序。
- 目标电脑界面检查：在独立数据目录运行 x64 测试实例，反复点击两台显示器并查看色域图，验证手动刷新、模拟显示配置通知、最小窗口滚动、三次 CPU 详情往返、显卡与 SMART 入口、历史和排序。关闭到托盘后 SQLite 继续写入样本，重新打开可继续操作。
- 目标电脑显示器：WLCD-27UH27 为 3840 × 2160、60.00 Hz、DisplayPort，估算 sRGB 覆盖率 100.0%。Q2790 为 2560 × 1440、59.95 Hz、HDMI，估算 sRGB 覆盖率 94.8%。两台显示器的 RGB 色度坐标及连接类型与 Windows WMI 读数一致。
- 目标电脑传感器：从已安装版本的新样本读到 CPU 封装温度 63 °C、封装功耗 6.36 W、GPU 温度 50 °C、板卡功耗 41.09 W。本次测试实例未启动独立的提权采集助手。
- 待验证：实际插拔及刷新率切换后的通知，x86 和 arm64 实机运行，以及替换已安装版本后的运行。
