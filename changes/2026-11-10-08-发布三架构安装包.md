# 发布 V0.1.0001 三架构安装包

## 原因

为 Windows x86、x64 和 ARM64 提供可下载的 V0.1.0001 安装包，并在仓库首页说明安装、监控和 MCP 接入。

## 改动

- 构建脚本支持三种架构，保留默认的 x64 构建入口。补充 x86 进程结构偏移校验，并嵌入 V0.1.0001 版本信息。
- 新增打包脚本和中英文工具名保留的中文说明。每个 ZIP 随附安装脚本、主程序、MCP 服务脚本和文档。
- 新增根目录 README。ZIP 保存在本地 package 目录，远程通过 GitHub Release 分发。

## 验证

- 默认 x64 构建以及 LLVM-MinGW 的 x86、ARM64 构建通过。核对三个 ZIP 的文件清单和内容、PE 架构及 V0.1.0001 版本资源。
- 未部署本次发布包，x86 和 ARM64 原生系统的安装、界面和硬件读数待实机验证。
