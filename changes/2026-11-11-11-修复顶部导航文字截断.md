# 修复顶部导航文字截断

## 改动原因

新增主板入口后，顶部导航的固定按钮宽度不足，导致「显示器」「主板」「设置」显示省略号。

## 改动内容

- 按当前字体测量五个导航标签的宽度，为每个按钮保留足够的文字区域。窗口有余量时增加按钮宽度，窄窗口使用较小的导航内边距。

## 验证结果

- 使用 `./build.ps1` 构建 x64，并通过 `./install.ps1` 安装。实际运行路径为 `C:/Program Files/ComputerWatch/ComputerWatch.exe`，安装文件和构建产物的 SHA-256 一致。
- 用 GDI 验证 100%、125%、150%、175%、200%、250%、300% 七档缩放，五个标签在 550 逻辑像素窗口含滚动条的可用宽度内均可完整绘制。
- 已安装窗口的无障碍树包含五个导航按钮，SQLite 在更新后持续写入。截图捕获超时，安装版的视觉核对和 CPU 详情往返待验证。
