# 实时资源卡逐件显示硬件型号

## 原因

实时卡片原先只显示指标，无法识别当前电脑安装的处理器、内存、物理盘和显卡。多件同型号硬件也需要逐件展示。

## 改动

- 首次打开面板时在后台读取本机硬件清单，后续采样复用结果。处理器按已装插座、内存按已装插槽、磁盘按物理盘编号、显卡按当前即插即用设备实例列出。
- 处理器和内存读取 SMBIOS，CPU 首项可回退到 Windows 的处理器名称。磁盘复用 SMART 页的设备标识读取逻辑，清单只读取描述符。显卡清单支持不同厂商，并排除 ROOT、SWD 软件枚举显示设备。NVML 仍负责原有的显卡传感器采样。
- 实时卡新增型号区域，保留同型号设备各自的行。当前硬件清单仅放在实时页。型号缺失时明确显示，长名称可悬停查看。

## 验证

- 项目根目录运行 `./build.ps1` 成功，构建无警告。实际启动项目构建版，未更新安装版本。
- 本机截图显示 Xeon E5-2697A v4、A1/B1/C1/D1 四条内存、两块物理盘及一块 RTX 3060。已与 Windows 的 CIM 和 PnP 枚举交叉核对，三条同型号 Micron 内存均独立显示。
- 检查 100% 与 125% 缩放、720×570 窄窗口，完成三次实时页与 CPU 详情往返，并检查 GPU 详情、SMART 和历史入口。实时卡仍显示 CPU 与 GPU 实测温度及功耗。
- 当前清单在一次运行内缓存。多插座、多物理显卡和设备热插拔未做实机覆盖。
