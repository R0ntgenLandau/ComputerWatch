# 新增内存详情和独立时序采集候选

## 改动原因

内存卡片需要详情页及可展开的占用率曲线。后续要求增加可独立分发的当前时序自动采集，并如实记录平台适配、字段覆盖及实机验证缺口。

## 改动内容

- 内存详情展示已安装、系统可见、已用、可用、提交量与上限、提交峰值、系统缓存、分页池、非分页池、页大小及硬件保留估算。
- 使用现有 SMBIOS 枚举逐设备读取容量、空插槽、制造商、型号、序列号、Bank、代际、封装、位宽、Rank、配置与标称速率和电压。旧 SMBIOS 速率标为固件原值。
- 首页内存曲线可点击展开，详情保留实际采样点构成的最近 60 秒曲线。历史报告仅作为备用对照。
- 新增独立原生内存时序模块、CPUID 分派和结构化字段。通过已有提权助手 IPC 异步读取，仅详情页按需请求，每分钟最多一次，底层子进程 5 秒超时。源代码仅调用读取接口。
- 嵌入官方签名 AMDFamily17 和 IntelMCHBAR 0.2.11 模块。增加 AMD Matisse / Vermeer DDR4 的两个 UMC、83 个源位域及刷新、命令率等附加解码。所有 AMD 结果明确标记尚未实机验证。
- x64 候选包增加固定摘要、签名校验的官方 PawnIO 2.2.0 安装器及安装更新流程，默认卸载保留共享驱动，显式选项可以移除。记录候选包的再分发材料审核缺口。
- MEMORY_TIMINGS.md 提供硬件平台矩阵、逐字段表、实际验证、后续条件和可执行验收步骤。

## 实际验证

- 在项目根目录运行 build.ps1；x86、x64、ARM64 编译与打包通过。构建产物、安装包和测试辅助文件保留在 Git 忽略的 build/。
- 本机为 Xeon E5-2697A v4，Family 6 / Model 79 / Stepping 1，固件主板标识 INTEL X99，4 × 16 GiB DDR4。设备数据与 Windows CIM 对照通过。
- 普通权限 PawnIO 打开返回 0x80070005。提权后打开成功，签名 IntelMCHBAR 模块加载失败 0x80070032。已安装版本的原生 IPC 确认同一失败原因。当前自动读取到的时序字段为 0 项。
- 临时原生 UI 测试通过曲线展开/收起、详情滚动、持续采样、三次实时监控与 CPU 详情往返、托盘关闭与重开。截图捕获超时，视觉验收尚未完成。
- 超时故障注入测试在 5022 ms 返回 read_failed 和空字段，采集子进程退出。
- 本机执行更新、默认卸载和重新安装，实际程序路径为 C:/Program Files/ComputerWatch/ComputerWatch.exe，核对安装文件与构建 SHA-256 一致，两个计划任务恢复 Running。依赖安装器复制到安装目录。
- 重装后的 SQLite 样本持续写入，09:53:09 记录 CPU 温度 61 °C、CPU 封装功耗 7.05 W、GPU 温度 50 °C、GPU 板卡功耗 41.59 W。属于本软件采集值。

## 待完成

完整时序目标尚未完成。本机缺少可用的 Broadwell-EP 签名读取后端和已验证解码。AMD 样机、字段全集闭合和逐项精度验证、无第三方工具的干净部署、首次驱动安装、重启验收、共享驱动卸载以及正式分发的对应源码材料审核均未完成。候选包不作为完整时序正式发行版。
