# 新增网络实时详情

## 改动原因

实时监控的网络卡片只显示收发流量，需要能查看当前连接和网卡数量。

## 改动内容

- 在实时监控的网络卡片加入「详情」，显示当前下载、上传以及物理网卡和虚拟网卡数量。
- 网卡按 Windows 接口表的硬件标记分类。计数包含系统枚举到的断开、禁用及隐藏网卡，排除软件环回和过滤接口。
- 当前连接按网卡展示，优先显示有默认网关的连接。可查看名称、型号、MAC 地址、接收和发送链路速率、IPv4、IPv6、默认网关和 DNS。物理网卡在接口活动时显示，虚拟网卡需有可读取的 IP 地址。
- 扩展网络信息随详情页采集，收进托盘后停止读取扩展信息。

## 验证结果

- `./build.ps1` 构建 x64 成功。通过 `./install.ps1` 更新本机，安装文件与构建产物 SHA-256 一致，运行路径为 `C:/Program Files/ComputerWatch/ComputerWatch.exe`。
- 在目标电脑直接调用新增采集函数，读到 2 张物理网卡、24 张虚拟网卡和 5 个活动连接。核对 Windows 接口标记及 IP 配置，覆盖 WLAN、Hyper-V 和 VMware 的活动连接，成功读到 IPv4、IPv6、MAC、链路速率和 DNS，WLAN 读到默认网关。
- 已安装窗口的可访问性树包含网络详情按钮。SQLite 最新记录推进了约 5 秒。桌面点击报坐标不可用，截图捕获超时，网络详情滚动、返回实时监控及 CPU 详情往返待交互核对。
