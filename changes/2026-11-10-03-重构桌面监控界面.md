# 重构桌面监控界面

## 原因

旧界面顶部占用较多空间，资源卡的图表和指标缺少统一布局，深色下拉框和排行表与页面风格有差异。

## 改动

- 沿用原生 Win32、GDI 双缓冲和现有深浅主题入口。压缩应用栏，统一深色表面、蓝色状态强调、按钮、选择器、详情表头与滚动条主题。
- 对齐五张卡片的标题、主指标、辅助信息、图表工具行和趋势图。标明磁盘已用容量和网络下载速率，使用等宽数字、浅色填充和双色图例。图表使用原有采样时间、百分比尺度和断点规则。
- 进程排行使用轻分隔线、悬停行、弱化的 PID 和排序箭头。宽窗口双栏，窄窗口改为上下排列，长进程名保留完整提示。
- 保留 Windows 标题栏、日期键盘编辑、原生弹窗和每用户主题选择。按钮和选择器状态即时更新。

## 验证

- 编译检查：在项目根目录运行 `./build.ps1` 成功，生成 `build/ComputerWatch.exe`，最终构建无编译警告。未引入模拟数据。
- 运行检查：直接启动项目构建产物。实际走通实时监控与 CPU 详情往返三次、显卡详情、磁盘 SMART、历史查询和趋势定位、深浅主题切换、两组排行排序、下拉键盘选择、最小化和最大化、关闭到托盘和重新打开。
- 布局检查：100% 下检查 1150×720 宽窗口和 720×570 窄窗口，后者可滚动查看上下排列的进程表。跨屏实际验证 125%（120 DPI），并生成实拍截图。当前显示器配置未覆盖 150%。
- 实机采样：实时页观察到 CPU 封装 66 °C、8.6 W，GPU 50 °C、42.8 W，均为应用实采读数。硬件采集实现未修改，本轮未使用外部工具交叉校准。
- 本轮运行项目构建产物，未执行安装脚本。试运行使用当前用户深色主题，注册的安装和启动配置沿用原配置。
