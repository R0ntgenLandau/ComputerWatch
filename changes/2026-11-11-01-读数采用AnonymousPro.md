# 界面读数采用 Anonymous Pro

## 原因

按用户指定为监控读数和英文标题使用 Anonymous Pro 等宽字体。

## 改动

- 将 Mark Simonson 发布的 Anonymous Pro Bold 嵌入程序资源，启动面板时在进程内加载。实时和历史资源卡主读数、详情大号读数及 Computer Watch 标题使用该字体。中文标签继续使用微软雅黑 UI。
- 在字体目录保留上游 SIL OFL 许可，后续生成的发布包随附该许可。

## 验证

- 默认 x64 构建及 x86、ARM64 交叉构建通过。
- 在 Windows 界面测试程序中核对 GDI 选中的字体名称和常用数字、符号字形。用模拟采样在常规和窄窗口下往返 CPU 详情三次，确认返回后仍能刷新实时数据。
- 本次未更新已安装版本或发布包。实际界面的视觉效果待人工核对。
