# 新增主板信息页

## 改动原因

监控面板缺少集中查看主板身份、固件和板载硬件的入口。

## 改动内容

- 顶部新增「主板」页，显示主板与模块的厂商、型号、硬件版本、序列号、资产标签、机箱内位置、类型和特性。
- 显示 BIOS 厂商、版本、发布日期、ROM 容量、系统 BIOS 和嵌入式控制器修订版、SMBIOS 版本、UEFI 支持及当前启动模式。
- 展开固件报告的扩展插槽、板载端口与接头、板载设备，并显示 Windows 枚举到的 ISA、LPC 或 eSPI 桥及 SMBus 控制器和 PCI 标识。
- 沿用首次显示面板时读取的硬件清单。固件未提供的字段显示横线，空清单有对应提示。[DMTF SMBIOS 规范](https://www.dmtf.org/sites/default/files/standards/documents/DSP0134_3.9.0.pdf) · [Windows 固件表接口](https://learn.microsoft.com/windows/win32/api/sysinfoapi/nf-sysinfoapi-getsystemfirmwaretable)

## 验证结果

- `./build.ps1` 编译 x64 成功，`./install.ps1` 安装成功。已确认实际运行路径为 `C:/Program Files/ComputerWatch/ComputerWatch.exe`，安装文件和构建产物 SHA-256 一致。
- 用临时程序直接调用本次采集函数，读到 X99 V1.0、BIOS 5.11、SMBIOS 3.0、传统 BIOS 启动，以及 7 个插槽、24 条端口记录、1 个板载设备和 2 个芯片组相关 PCI 设备。Windows CIM 的主板型号、BIOS、插槽和端口数量与之相符。
- 已安装窗口的无障碍树确认「主板」入口存在。窗口截图捕获超时，电脑操作随后被用户停止。主板页面的渲染、窄窗口滚动、CPU 详情三次往返及托盘重开待验证。未做模拟数据检查。
- 更新后本机 SQLite 持续写入。15:06:59 的样本记录 CPU 封装温度 62 °C、CPU 封装功耗 6.12 W、GPU 温度 49 °C、显卡板卡功耗 20.69 W。
