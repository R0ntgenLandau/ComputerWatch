# 修复顶部标题截断

## 改动原因

本机截图中，顶部品牌标题「Computer Watch」超过预留宽度，被显示为省略文本。

## 改动内容

- 为品牌标题使用 18 逻辑像素的专用字体，保留 Anonymous Pro 和 Segoe UI 回退，适配现有导航预留宽度。

## 验证结果

- 使用 `./build.ps1` 编译 x64，并通过 `./install.ps1` 更新本机。已核对安装文件的 SHA-256 和实际运行路径。
- 用 GDI 测量两种字体在 100% 至 300% 的七档缩放下的标题宽度，均小于预留宽度。本机在 100% 缩放下用 1150 和 550 逻辑像素窗口验证完整标题及导航。
- 已安装版本完成三次实时监控与 CPU 详情往返，并验证两台显示器可以切换选择。SQLite 继续写入样本，复核 CPU 封装温度 63 °C、封装功耗 7.29 W、GPU 温度 49 °C、板卡功耗 42.02 W。
