# 新增本机 MCP 查询

## 原因

让 MCP 客户端可以查询 Computer Watch 已采集的监控数据。

## 改动

- 新增按需启动的 stdio MCP 服务。使用官方 Python SDK，以当前 Windows 用户权限只读打开现有历史数据库。
- 提供最新或指定时刻的落盘快照，包含当时的 CPU 与内存前 10 名。时间区间查询支持分页，保留数据库中的缺失值。
- 在 MCP.md 记录依赖、客户端配置和字段单位。

## 验证

- 通过 Windows 上的 MCP SDK 客户端验证 stdio 初始化、工具发现、现有历史库的最新和指定时刻快照、区间分页，以及非法参数和缺失数据库的错误返回。
- 根目录执行 build.ps1 时，正在运行的 ComputerWatch.exe 锁住了输出文件。在独立目录复用同一构建脚本，成功生成 ComputerWatch.exe。
- SDK 依赖在启动时向 stderr 输出一条 Pydantic 字段定义警告，工具调用通过。
